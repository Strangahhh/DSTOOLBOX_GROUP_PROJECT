## เกี่ยวกับโปรเจค (About the Project)

โปรเจคนี้คือ "Rubrop" เว็บแอปพลิเคชันที่พัฒนาด้วย Django สำหรับการจัดการอีเวนต์และรูปภาพภายในอีเวนต์ โดยมีความสามารถหลักในการใช้เทคโนโลยีรู้จำใบหน้าเพื่อค้นหารูปภาพบุคคลที่เกี่ยวข้องในอีเวนต์นั้นๆ

### ฟังก์ชันหลัก:
- **การจัดการอีเวนต์:** สร้าง, แก้ไข, และจัดการรายละเอียดอีเวนต์ รวมถึงการเพิ่มทีมงาน
- **การอัปโหลดรูปภาพ:** อัปโหลดรูปภาพสำหรับแต่ละอีเวนต์
- **การรู้จำใบหน้า:** ระบบจะตรวจจับและเข้ารหัสใบหน้าจากรูปภาพที่อัปโหลด ผู้ใช้สามารถอัปโหลดรูปใบหน้าของตนเองเพื่อให้ระบบค้นหารูปอื่นๆ ที่มีใบหน้านั้นในอีเวนต์ได้
- **QR Code:** สร้าง QR Code เพื่อให้เข้าถึงหน้าอีเวนต์ได้ง่าย
- **ดาวน์โหลดรูปภาพ:** ดาวน์โหลดรูปภาพทั้งหมดของอีเวนต์ หรือเฉพาะรูปภาพที่ตรงกับใบหน้าที่ค้นหา (ในรูปแบบไฟล์ ZIP)
- **การยืนยันตัวตน:** ระบบลงทะเบียนและเข้าสู่ระบบสำหรับผู้ใช้

โปรเจคนี้เป็นส่วนหนึ่งของ DSTOOLBOX_GROUP_PROJECT และโค้ดหลักของแอปพลิเคชัน Rubrop อยู่ในไดเรกทอรี `dstool_x/rubrop`
